# flare-lensing.github.io

Source for the FLARE website, <https://flare-lensing.github.io>.

It is a single static page (`index.html`, styles inline) plus images in `assets/`, served by
GitHub Pages from the `main` branch. There is no build step. `.nojekyll` turns off Jekyll
processing.

To preview locally:

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```

This repository is public. Keep unpublished results, private repo links and anything from
the members-only org profile out of it until the matching paper is out.
